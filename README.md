# Screen Translator (Экранный Переводчик)

Минималистичный экранный переводчик для Windows в стиле **Win + Shift + S** (Snipping Tool) и **Google Lens / Circle to Search**.

Выделяйте любую область экрана и получайте перевод текста прямо поверх оригинала без лишних окон, кнопок и визуального шума.

![Screen Translator Demo](demo.png)

## Особенности

* **UX в стиле Win + Shift + S:**
  * Никаких постоянно висящих панелей на рабочем столе. Приложение тихо работает в системном трее.
  * Затемнение экрана и аккуратная тонкая белая рамка выделения.
  * Крестик курсора появляется только при зажатии мыши для выбора области и исчезает после отпускания.
* **In-Place замена текста (как в Circle to Search):**
  * Встроенный оффлайн **Windows OCR** (`winocr` на базе WinRT API). Мгновенное распознавание слов и строк с сохранением точных экранных координат (DPI-aware).
  * Умная кластеризация строк: слова на одной горизонтальной линии объединяются в цельные предложения.
  * Автоматический подбор цвета фона и контрастного текста.
  * Бесшовное перекрытие без рамок и контуров.
* **Интерактивный текст и выделение мышью:**
  * Возможность выделить мышью **любой фрагмент, слово или несколько строк** и скопировать через **`Ctrl + C`** (или `Ctrl + A` для всего текста).
  * Двойной клик ЛКМ аккуратно выделяет и копирует слово под курсором с учётом границ слов.
* **Быстрое управление с клавиатуры:**
  * **`Alt + Q`** или **`Ctrl + Shift + S`** (а также `Alt + T`) — мгновенный запуск оверлея из любой программы.
  * **`Tab`** — переключение между переводом и оригиналом прямо на месте.
  * **`F4`** — открытие компактной тёмно-серой палитры языков с мгновенным переключением клавишами `1`–`9` и авто-переводом на лету.
  * **`Esc`** или клик за пределами области — мгновенный выход.
* **Надёжность и стабильность:**
  * Атомарный системный мьютекс Windows (`CreateMutexW`): гарантирует ровно один активный экземпляр процесса и исключает дублирование иконок в трее.
  * Использование штатного Win32 `RegisterHotKey`: не блокирует системную раскладку и переключение языка `Alt + Shift`.

## Установка

Требуется **Python 3.10+** и Windows 10/11.

```bash
git clone https://github.com/arturg-sudo/screen-translator.git
cd screen-translator
pip install -r requirements.txt
```

---

## Запуск

### Запуск в фоне:
Дважды кликните по `run.bat` или запустите:
```bash
pythonw main.py
```

### Мгновенный вызов переводчика:
```bash
python main.py --now
```

## Горячие клавиши

| Клавиша / Сочетание | Действие |
| --- | --- |
| **`Alt + Q`** / **`Ctrl + Shift + S`** / **`Alt + T`** | Активировать экранный переводчик |
| **`Tab`** | Показать оригинал / перевод на месте |
| **`F4`** | Открыть палитру выбора языков (`1`–`9`) |
| **`Ctrl + C`** | Скопировать выделенный текст (или двойной клик по слову) |
| **`Ctrl + A`** | Выделить весь переведённый текст |
| **`Esc`** | Закрыть оверлей |
